<h4>Report on</h4> 
Exam Pilot: Jira managements </br>
This report records the comprehensive application of Atlassian Jira for managing the maintenance activities of the Exam Pilot web application, which resulted in the successful upgrade from version 1.0 to version 1.1. 
The implementation includes a customized Kanban workflow with specialized testing and approval processes, custom fields for team collaboration, and structured issue management.
